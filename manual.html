🧠 메모리온 (MemoryOn) 사용설명서

가림막 백지복습 · AI 아나운서 음성 회독 · 간격 반복(Anki)을 하나로 결합한 스마트 암기 스튜디오 공식 매뉴얼입니다.

🚀 메모리온 암기장 바로 실행하기

📱 1. 휴대폰 & PC에 전용 앱으로 설치하기

🤖 갤럭시 / 안드로이드 휴대폰

크롬(Chrome), 삼성 인터넷, 또는 모바일 Edge 앱으로 접속한 뒤 메뉴(⋮) → [앱 설치] 또는 [홈 화면에 추가]를 누르면 바탕화면에 정식 앱 아이콘이 생성됩니다.

🍎 아이폰 / 아이패드 (iOS)

사파리(Safari) 브라우저로 접속한 뒤 하단 중앙의 [공유하기(네모 위 화살표)] 버튼 → [홈 화면에 추가]를 누르면 바탕화면에 앱으로 설치됩니다.

💻 PC에서 최고 음질(MS 선희·인준 아나운서)로 사용하기

윈도우 PC에서는 마이크로소프트 엣지(Edge) 브라우저로 열면 최고급 신경망 성우인 선희(여성 아나운서)와 인준(남성 강사) 목소리가 무료로 자동 연결됩니다.

🔒 개인정보 및 데이터 독립성 안내: 메모리온의 모든 암기 카드와 메모는 서버가 아닌 사용자 본인의 스마트폰/PC 내부 저장소(IndexedDB)에만 저장됩니다. 같은 주소를 여러 사람이 써도 내 공부 내용은 오직 내 기기에만 보입니다.

🎯 2. 4단계 가림막(빈칸) 학습 & 순차 열기

4가지 가림막 모드 전환

• 🔴 그림+빨간글씨+암기표 가장 추천하는 기본 모드입니다. 핵심 키워드와 하단 요약표만 가려줍니다.
• 🔒 백지복습(전체) 소제목만 남기고 본문 문장 전체를 가려 백지 인출 훈련을 돕습니다.
• 🎯 하단 암기표만 본문은 보면서 맨 아래 두문자·핵심 요약표만 빠르게 점검합니다.
• 👀 모두 펼치기 가림막을 모두 벗기고 일반 서브노트처럼 통독합니다.

🔓 다음 빈칸 순차 열기 & ✂️ 내 맘대로 빈칸 추가하기

• 하단 리모컨의 [🔓 다음빈칸] 버튼(PC는 Enter)을 누르면 위에서부터 순서대로 빈칸이 하나씩 열리며 화면이 자동 스크롤됩니다.
• 공부 도중 새로 빈칸을 뚫고 싶은 단어가 있다면, 글자를 마우스로 드래그(또는 우클릭)하거나 [✂️ 가림막 편집]을 눌러 즉시 빨간 빈칸/파란 빈칸으로 만들 수 있습니다.

🎧 3. AI 아나운서 음성 회독 (귀로 듣는 서브노트)

4가지 재생 모드 지원 (단축키 R 또는 하단 리모컨으로 전환)

1. 🔊 현재 문제 1회 듣기: 지금 보고 있는 카드만 끝까지 읽고 멈춥니다.
2. 🔂 현재 문제 무한 반복: 안 외워지는 문제를 계속 반복 낭독합니다. (1회독이 끝날 때마다 열렸던 빈칸을 다시 자동으로 덮고 반복합니다)
3. ▶️ 연속 듣기 (현재 ~ 끝): 현재 문제부터 마지막 문제까지 자동으로 페이지를 넘기며 연속 낭독합니다.
4. 🔁 전 구간 무한 순환: 1번 문제부터 끝 문제까지 무한 회전하며 읽어줍니다 (이동 중 귀로 회독할 때 최적).

🎙️ 아나운서 목소리 및 배속 변경

상단 [⚙️ 음성/배율] 버튼을 누르면 4가지 아나운서 프리셋(표준 브리핑 / 중저음 강사 / 또렷한 딕션 / 속독 브리핑)과 배속(0.9배속 ~ 1.5배속)을 자유롭게 조절할 수 있습니다.

➕ 4. 암기 카드 추가 & 제작하는 3가지 방법

방법 ①: [➕ 카드 직접 추가] 탭 (가장 간편한 자체 에디터)

• 🅰️ 문답형(Basic): 앞면에는 질문/기출문제를, 뒷면에는 정답과 해설을 입력합니다.
• 🅱️ 서브노트·빈칸형(Cloze): 개조식 요약 노트를 적고 원하는 단어를 {{빨간빈칸}} 또는 [[파란빈칸]]으로 감싸기만 하면 자동으로 가림막이 생성됩니다. (클립보드 캡처 이미지를 Ctrl+V로 바로 붙여넣을 수도 있습니다)
• ⚡ 대량 일괄 등록: 문제 :: 정답 || 메모 형식으로 여러 줄을 한 번에 붙여넣어 수십 개의 카드를 1초 만에 생성합니다.

방법 ②: [📂 HWPX 업로드] 탭 (한글 서브노트 자동 변환)

한글(HWPX)로 작성된 서브노트 파일을 업로드하면 ■ 기호를 기준으로 단원을 쪼개고, 빨간색 글씨·파란색 암기표·도면 이미지·우측 하단 과목명을 자동 인식하여 암기 카드로 변환합니다.

방법 ③: [📸 손글씨→노트 스튜디오] 탭

손글씨 서브노트 사진을 올리고 개념도를 드래그하면 줄노트 가로줄을 깨끗하게 지워주며, 한글(HWP) 문서에 바로 붙여넣을 수 있는 표 서식과 암기 카드를 동시에 만들어 줍니다.

🚩 5. 6색 컬러 플래그 & 간격 반복(Anki) & 백업

🎨 6색 컬러 플래그 & 🩸 취약(Leech) 문제 자동 분류

• 카드 우측 상단의 6가지 색깔 점을 눌러 '시험직전 최우선(빨강)', '자주 틀리는 함정(주황)', '수식·계산(노랑)' 등 나만의 기준대로 분류하세요.
• 하단 평가 버튼에서 [1. 다시(Again)]을 누적 4회 이상 누른 카드는 자동으로 🩸 취약(Leech) 배지가 붙어 특별 관리됩니다.
• [🚩 플래그/카드 관리] 탭에서 특정 색깔 플래그나 취약 카드만 골라 [🎯 집중 학습하기] 또는 [🎧 연속 TTS 듣기]를 실행할 수 있습니다.

💾 JSON 파일 백업 & 기기 간 1초 연동 (PC ↔ 스마트폰)

[💾 백업/복원] 탭에서 [JSON 파일로 내보내기]를 누르면 내가 만든 모든 카드·이미지·메모·암기 이력이 파일 하나로 저장됩니다. 이 파일을 카톡으로 보내 휴대폰이나 다른 PC에서 불러오면 100% 똑같이 복원됩니다.

⌨️ 6. PC 키보드 단축키 모음

Enter 또는 E다음 빈칸(가림막) 하나씩 순서대로 열기
Space (스페이스바)현재 카드의 모든 가림막 한 번에 펼치기 / 다시 덮기
← / → 방향키이전 문제 / 다음 문제로 이동
TAI 아나운서 음성 듣기 시작 / 일시정지
